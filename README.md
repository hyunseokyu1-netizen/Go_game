# 바둑 배움터

초보자를 위한 바둑 게임. 형세분석, 추천 수, "여기 두면 어떻게 잡히는지" 수순 설명을 보면서 둘 수 있어요.

## 실행

빌드 없이 `index.html`을 브라우저로 열면 됩니다. 로컬 서버로 열 수도 있어요.

```bash
python3 -m http.server 8765   # → http://localhost:8765
```

## 기능

- **대국**: 9·13·19줄, 컴퓨터(쉬움/보통/어려움) 또는 2인 연습, 무르기, 패스, 계가(죽은 돌 자동 추정 + 클릭 수정)
- **형세분석**: 판 위 네모로 예상 집 표시, 흑/백 예상 집 수와 우세 막대
- **추천 수**: 상위 3수를 번호로 표시하고 이유(따냄·살림·단수·집 증가·초반 3/4선 등)를 함께 보여줌
- **이 자리에 두면?**: 빈 자리를 한 번 누르면 미리 분석하고, 한 번 더 누르면 둠
  - 잡히는 수는 종류(단수 / 몰아잡기 / 축 / 장문)와 수순을 글로 설명
  - "▶ 어떻게 잡히는지 판에서 보기": 번호가 붙은 돌로 수순을 재생 (◀ ▶, 자동 재생)
- **급한 곳 알림**: 위험한 내 돌(빨간 테두리)과 잡을 수 있는 상대 돌, 살리는 자리 안내
- **위험한 자리 ✕ 표시**: 두면 바로 잡히는 자리

## 구조

| 파일 | 역할 |
|---|---|
| `js/board.js` | 규칙 엔진 (따내기, 자살수, 패) |
| `js/tactics.js` | 수읽기 (단수·축·장문 탐색, 수순 주석) |
| `js/analysis.js` | 세력 기반 형세 추정, 사석 추정, 계가 |
| `js/advisor.js` | 모든 착점 평가 → 추천/경고/이유, AI 착수 |
| `js/app.js` | 캔버스 렌더링과 UI |
